## Подключение GitHub

Попытка `gh auth status` завершилась ошибкой: команда `gh` не найдена.
Она также не найдена в стандартном `C:\Program Files\GitHub CLI\gh.exe`.
Это не доказательство отсутствия GitHub-аккаунта или авторизации в браузере:
локальный CLI недоступен, поэтому состояние его авторизации неизвестно.

Простой способ на Windows:

```powershell
winget install --id GitHub.cli --exact
# Открыть новое окно PowerShell, затем:
gh auth login --hostname github.com --git-protocol https --web
gh auth status
```

Войти в браузере в нужный аккаунт и подтвердить показанный одноразовый код.
Не вставлять токены в README, исходники или переписку.
Источники: https://github.com/cli/cli#installation и
https://cli.github.com/manual/gh_auth_login.

## Хранение весов и данных

Для этого небольшого проекта выбраны **GitHub Releases**, без Git LFS:
это сохраняет Git-историю лёгкой и позволяет хранить обе версии модели.
По правилам GitHub обычный Git предупреждает о файлах свыше 50 MiB и блокирует
файлы свыше 100 MiB; бинарные файлы удобно распространять через Releases:
https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github.

Локально в `.publication/` подготовлены:

| Asset | Байты | Содержимое |
|---|---:|---|
| csai3210-first-best.pt | 24 073 291 | Первая модель, без изменений |
| csai3210-second-best.pt | 24 053 387 | Дообученная экспериментальная модель |
| csai3210-tashkent-originals-and-crops.zip | 32 835 378 | 76 оригиналов, 52 активных кропа, разметка |
| csai3210-commons-reviewed.zip | 102 731 385 | 502 принятых кропа, лицензии и атрибуция |

`release_assets.json` содержит SHA256 и пути восстановления; рядом с архивами
есть `SHA256SUMS.txt`. ZIP CRC и содержимое каждого файла проверены против
локального исходника. Архивы не загружены. Никакого фиктивного URL нет.
Публикация оригинальных ташкентских фото остаётся частью будущего отдельного
подтверждения владельца. Для Commons сохраняются лицензии каждого файла;
общая лицензия CC0 на весь датасет не назначается. Условия Ultralytics и статус
лицензии собственного кода описаны в `THIRD_PARTY_NOTICES.md`.

Восстановление на чистом клоне: распаковать оба ZIP в корень, не меняя пути,
поместить оба `.pt` в соответствующие `runs/first/best.pt` и
`runs/second/best.pt`; первую модель также скопировать в
`runs/second/baseline_best.pt` для тестов и протокола дообучения.
