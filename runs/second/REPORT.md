# CSAI-3210: публичное дополнение и дообучение

Дата: 26 октября 2026. Итог: увеличение данных **не улучшило распознавание марок** на исходной проверке Ташкента. Новая модель сохранена как экспериментальная; первая модель не заменена.

## Проверенный результат

Обе модели проверены одним кодом, с одинаковым Resize(224,224), ImageNet-нормализацией и без аугментаций на тех же 10 исходных кропах. Объекты из одной физической группы и исходной фотографии исключены из обучения. Доверять этому результату как оценке всех машин Ташкента нельзя: выборка мала, несбалансирована и уже использовалась для выбора первой модели. Для новой модели она использована только после выбора лучшей эпохи на публичном development.

| Метрика на исходных кропах | Первая модель | Новая модель |
|---|---:|---:|
| Brand top-1 | 1/10 = 10% | 1/10 = 10% |
| Colour top-1 | 6/10 = 60% | 7/10 = 70% |
| Оба выхода одновременно | 1/10 = 10% | 0/10 = 0% |
| Brand macro-F1 по представленным классам | 0.1667 | 0.0476 |
| Brand по 7 группам машин, усреднение вероятностей | 1/7 = 14.29% | 1/7 = 14.29% |
| Colour по 7 группам машин | 4/7 = 57.14% | 4/7 = 57.14% |

Прирост цвета на кропах равен одному объекту; на уровне групп машин прироста нет. Новая модель ошибается иначе: старый правильный BMW стал BYD, один из BYD теперь правильно распознаётся по марке, но ошибочно по цвету. Улучшение в целом не подтверждено. Не следует выбирать победителя или настраивать параметры по повторным запускам на этих десяти объектах.

Полные данные: `comparison.json`, `old_benchmark_predictions.json`, `new_benchmark_predictions.json`, отдельные vehicle predictions; матрицы ошибок — CSV и PNG `brand_confusion.png`, `colour_confusion.png`. Нулевой support обозначен отсутствием оценки, а не точностью 0%.

В исходной проверке присутствуют BMW, BYD, Chevrolet, Deepal, Kia, Leapmotor. **Невозможно проверить на Ташкенте** Aion, Changan, Chery, Geely, Haval, Jetour, Li Auto, Skoda, Tesla, Toyota, Voyah, Zeekr. Из цветов в проверке есть только black, white, grey; red, blue, green, brown, yellow не проверяются. Публичные снимки этих классов не заменяют местную проверку.

## Выполнение эксперимента

RegNet-Y-800MF, два выхода brand/colour, 18 марок и 8 цветов. Warm start из собственных `runs/first/best.pt`; существующие строки выхода brand перенесены по именам классов, Changan/Geely/Jetour инициализированы случайно. Внешний классификатор марок не использован.

Один фиксированный запуск: 40 эпох, batch 16, seed 3210, AdamW, body LR 1e-5, heads LR 3e-4, cosine schedule, weight decay 0.03, label smoothing 0.1, веса brand/colour 0.7/0.3. Первые 8 эпох backbone заморожен. BatchNorm пересчитан только по train и затем заморожен. Балансировка по маркам, уменьшение вклада многочисленных серий, дополнительный вес локальным данным; неизвестные цвета маскируются. Аугментации не меняют hue/saturation. Полный протокол зафиксирован до обучения в `config.json`.

CUDA на NVIDIA RTX 4070 SUPER; PyTorch 2.9.1+cu128. Цикл обучения и development-проверки: **82.07 секунды** (не включает поиск, скачивание, ручную проверку, подготовку и финальный benchmark). Пик выделенной памяти PyTorch: 525209600 байт. Лучшая эпоха 31, выбрана по 0.7×brand balanced accuracy + 0.3×colour balanced accuracy только на публичном development. На этом development balanced accuracy brand 18.03%, colour 81.25%; это критерий выбора, не независимый тест.

Веса: `best.pt`, **24053387 байт** (24.05 MB / 22.94 MiB). SHA256: `d8149c8bd7ae0d69142b6fda2398dd8d713c5581cd0e105ac2d3af49ff710c55`.

Старая модель: `../first/best.pt`, резервная копия `baseline_best.pt`; SHA256 обеих `4dd17d10e9b1a6d92b5e2bc7a11b1c8027abf2d1278d643c755a14c3966e74e8`. Оригинальные 76 фотографий проверены по исходному SHA256, все совпали. Исходные метки и fingerprint также совпали.

11 автоматических тестов прошли: перенос строк головы, маскирование отсутствующего цвета, целостность файлов и лицензий, разделение групп и отсутствие одинаковых файлов между train/holdout, прежние проверки проекта. Код эксперимента сохранён в `source/`; историю обучения см. `history.csv`, графики — `learning_curves.png`.

## Чего не хватает

Данных всё ещё недостаточно: для ряда марок в Ташкенте есть только одна независимая машина, для новых Changan/Geely/Jetour местных проверочных примеров вообще нет. Нужны новые физические машины каждой марки, разные модели, ракурсы, освещение и цвета, включая обычные местные Chevrolet. Особенно важен новый заранее отложенный слепой тест, собранный отдельно от нынешней validation. Выставочные снимки Commons и повторяющиеся авторские серии дают сильное доменное смещение; простое увеличение числа таких снимков проблему не решило. Дальнейшую настройку следует вести на development, сохраняя новый местный тест закрытым.
